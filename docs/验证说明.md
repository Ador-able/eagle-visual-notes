# 验证说明

验证环境：Windows，Eagle 4.0 Build 23。集成验收使用 Electron 22.3.27、Chromium 108、Node.js 16.17.1 加载 `dist/` 中的页面；构建工具运行在 Node.js 24。

## 已验证

`npm run package` 已通过类型检查、打包与安装包生成。`npm run verify` 已通过 18 项集成检查，覆盖以下行为：

- Inspector 与工作台读取同一原生注释，编辑后保存并同步；立即切图、重新加载页面后内容正确。
- 保存失败时保留窗口内容并暂停切图，重试后恢复；切库后核对归属；多个编辑来源遵循最后保存。
- 未选择、多选状态；字号、行距、分栏恢复；图片缩放与平移保持笔记布局不变。
- Markdown 常用快捷键及格式切换、导出、备份与只补充空白注释的恢复。
- 更多菜单点击外部或按 Esc 关闭；首末张提示悬浮显示、自动消失，出现前后双栏尺寸不变。
- Markdown 中的原始 HTML 和脚本链接不执行；深浅主题及最小窗口没有横向溢出，未捕获页面脚本异常。

这些检查加载真实构建产物、CodeMirror、markdown-it 和缩放组件，仅将 Eagle API 边界替换为隔离夹具。保存结果从夹具数据文件重新读取，导出与备份从实际文件核对。脚本不连接个人 Eagle 素材库。

本机 Eagle 已实际安装并打开安装包，确认插件菜单入口、双栏工作台、原生注释读取、Inspector 渲染、暖金色加粗、点击正文关闭菜单和窗口最大化。安装目录中的脚本和样式与构建产物进行哈希比对。

## 未覆盖的实机范围

macOS、Eagle Build 12～22、多显示器拔插、整库重启恢复和大量图片库的性能没有实机验证。保存故障、跨库切换与并发编辑主要由隔离集成检查覆盖，不等同于真实断电或磁盘拔出的验证。最小化、关闭及全屏的完整桌面操作流程仍需在目标设备上验收。

## 重现

```sh
npm ci
npm run package
npm run verify
```

结果与运行时信息写入 `artifacts/verification/results.json`；同目录保留深浅主题、最小窗口和 Inspector 截图。README 截图使用自制 SVG 和示例注释。
