# 验证说明

验证环境：Windows，Eagle 4.0 Build 23。集成验收使用 Electron 22.3.27、Chromium 108、Node.js 16.17.1 加载 `dist/` 中的页面；构建工具运行在 Node.js 24。

## 已验证

`npm run package` 已通过类型检查、打包与安装包生成。`npm run verify` 已通过 28 项集成检查，覆盖以下行为：

- 工作台读取原生注释，编辑后保存并同步；立即切图、重新加载页面后内容正确。
- 保存失败时阻止关闭；关闭后释放窗口，再次运行恢复已保存内容，重复运行保持单实例。
- 保存失败时保留窗口内容并暂停切图，重试后恢复；切库后核对归属；多个编辑来源遵循最后保存。
- 未选择、多选状态；字号、行距、分栏恢复；图片缩放与平移保持笔记布局不变。
- H.264/AAC MP4 的首帧解码、实际播放、暂停、定位和音量设置；含中文、空格和井号的文件路径可读取。
- 视频与图片混合导航；视频笔记立即切换时保存，隐藏窗口暂停，切回图片后清除视频源并移除播放器。
- 视频解码失败时仍可编辑和保存笔记，系统播放器入口传入原文件路径；备份与恢复包含视频注释。
- Markdown 常用快捷键及格式切换、导出、备份与只补充空白注释的恢复。
- 三种模式切换不改写未编辑的原始 Markdown；渲染编辑、链接插入与修改、Markdown 粘贴、表格及嵌套列表往返；立即切图保存、撤销历史隔离和渲染模式恢复。
- 更多菜单点击外部或按 Esc 关闭；首末张提示悬浮显示、自动消失，出现前后双栏尺寸不变。
- Markdown 中的原始 HTML 和脚本链接不执行；深浅主题及最小窗口没有横向溢出，未捕获页面脚本异常。

这些检查加载真实构建产物、CodeMirror、Milkdown、markdown-it 和缩放组件，仅将 Eagle API 边界替换为隔离夹具。保存结果从夹具数据文件重新读取，导出与备份从实际文件核对。脚本不连接个人 Eagle 素材库。

Eagle 宿主实机检查覆盖固定到顶部工具栏、单击图标打开工作台、关闭工作台、插件菜单入口、原生注释读取、暖金色加粗、点击正文关闭菜单和窗口最大化。三种编辑模式通过隔离 Electron 验收，尚未在真实 Eagle 窗口中完成输入与模式切换验证。

1.3.0 已安装到本机，8 个分发文件与构建产物哈希一致。两段既有 MP4 的首帧、时长与笔记区域可正确显示；实测播放至约 10 秒后暂停、拖动到约 46 秒显示对应画面、切换静音和前后切换视频。实机视频笔记为空，未改写素材字段；视频笔记写入与失败处理由隔离集成验收覆盖。

独立工作台曾在本机正常退出后启动，未新增崩溃转储；该观察不等于长期稳定性保证，间歇性原生崩溃仍需继续观察。插件面板虽然显示默认快捷键 `Ctrl+Alt+M`，用户反馈无法触发；打开工作台使用已通过实机检查的工具栏图标。图标采用固定灰色 PNG，不随 Eagle 主题自动变色。

## 未覆盖的实机范围

macOS、Eagle Build 12～22、多显示器拔插、整库重启恢复和大量素材库的性能没有实机验证。保存故障、跨库切换与并发编辑主要由隔离集成检查覆盖，不等同于真实断电或磁盘拔出的验证。最小化和全屏的完整桌面操作流程、H.264/AAC 以外的视频编码仍需在目标设备上验收。

## 重现

```sh
npm ci
npm run package
npm run verify
```

结果与运行时信息写入 `artifacts/verification/results.json`；同目录保留深浅主题、渲染编辑、视频播放和最小窗口截图。README 截图使用自制 SVG 和示例注释。视频验收素材为仓库自带的合成色条与低音量正弦音，无需下载或安装转码工具。
