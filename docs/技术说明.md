# 技术说明

## 运行结构

插件通过 `manifest.json` 注册普通窗口。Eagle 启动时不创建工作台；点击固定的工具栏图标或插件面板入口时，由宿主创建单实例窗口，关闭按钮保存后销毁窗口。工具栏固定状态由 Eagle 保存。

笔记的唯一持久化来源是 Eagle 素材的 `annotation`。窗口尺寸、位置、字号、行距、分栏和模式保存在插件的 `localStorage`。

## 主要调用链

```text
Eagle 当前选择
  → workbench.syncSelection()
  → item.getSelected() + storage.loadNote()
  → mediaView.prepare() 准备图片或视频
  → 再次核对素材库和选中 ID
  → 同时更新媒体、编辑器与阅读视图

编辑器输入 / 格式快捷键
  → NoteEditor / RichNoteEditor 的同步变更回调
  → workbench.flush() 串行写入
  → storage.saveNote()
  → item.getById() 读取最新素材
  → 设置 annotation → item.save()
```

编辑过程中继续输入，会在当前保存结束后写入最新文本。切换素材先暂停视频并等待保存；图片解码后替换，视频在核对当前选择后加载原文件。视频加载不阻塞笔记编辑与后续选择查询。保存前后检查所属素材库，避免切库后按同 ID 保存到其他库。官方保存接口不提供跨素材库事务或多窗口条件更新；并行编辑遵循 Eagle 最后完成的保存。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `src/workbench.ts` | 素材同步、编辑状态、保存队列、窗口、菜单、分栏与快捷操作 |
| `src/editor.ts` | CodeMirror 编辑器、Markdown 格式与编辑快捷键 |
| `src/rich-editor.ts` | Milkdown 渲染编辑器、Markdown 读写与链接编辑 |
| `src/media-view.ts` | 图片解码与缩放、视频播放器与媒体资源释放 |
| `src/storage.ts` | 原生注释读写、JSON 备份与空注释恢复 |
| `src/shared.ts` | Markdown 渲染、主题与外部链接 |
| `src/files.ts` | 本地文件 URL 与原子写入 |
| `static/` | 页面、样式与图标 |
| `scripts/` | 构建、打包及 Electron 集成验收 |

## 失败处理

保存错误保留当前窗口中的文本并阻止切换素材，用户可以重试或导出。异常不会触发独立笔记存储。强制结束 Eagle 时，内存中尚未保存的输入无法恢复。

原图和 Eagle 预览图均无法解码时，在媒体区提示检查磁盘，注释仍可阅读。视频使用浏览器原生 `video` 控件；解码失败时保留笔记编辑能力，并通过 `eagle.shell.openPath()` 提供系统播放器入口。隐藏窗口暂停播放，切换素材和销毁窗口时清除视频源并调用 `load()` 释放媒体资源。

备份包含本库图片与视频的非空注释。恢复逐项提交，出现错误时停止；已经补充的注释保持已保存，再次执行会跳过非空注释。

Markdown 原始 HTML 被转义，避免注释在具有 Node.js 能力的插件页面执行脚本。链接只交给系统处理 HTTP、HTTPS 和邮件地址。构建将编辑器、渲染器、缩放组件和文件写入依赖打入插件，不从 CDN 加载脚本。

渲染编辑使用 [Milkdown 的 CommonMark 与 GFM 预设](https://milkdown.dev/docs/guide/using-milkdown-kit)，只读视图使用 markdown-it。正文事务同步更新当前 Markdown，保存队列不依赖防抖回调；装载内容时不触发保存。切图会重建两种编辑器的文档和撤销历史。模式切换按当前 Markdown 同步目标编辑器，内容相同时保留其历史。两种编辑器各自维护编辑文档，代价是额外的内存和约 1.1 MB 未压缩脚本体积。

## API 依据与代价

| 能力 | 使用方式与依据 |
| --- | --- |
| 独立窗口 | [窗口 API](https://developer.eagle.cool/plugin-api/api/window) 与 [manifest 配置](https://developer.eagle.cool/plugin-api/tutorial/manifest)：无系统边框，自绘窗口按钮，通过官方方法控制大小、位置、最大化、全屏和显示。 |
| 媒体与注释 | [item API](https://developer.eagle.cool/plugin-api/api/item)：使用选中素材、官方文件路径、`annotation` 和 `save()`，不直接改写素材库文件。主动选择素材要求 Build 12。 |
| 状态变化 | [事件 API](https://developer.eagle.cool/plugin-api/api/event)：接收主题与素材库变化。选图采用串行轮询，代价是同步延迟与后台读取。 |
| 本地文件 | [本地文件访问](https://developer.eagle.cool/plugin-api/tutorial/access-local-files)：Node.js 文件接口用于用户选择的导出文件和备份。 |

相邻素材导航需要读取当前文件夹候选并排序，素材很多时会增加切换等待。窗口隐藏时停止工作台选择查询。工作台重新打开需要重新初始化编辑器，代价是每次打开的初始化时间。视频直接读取原文件，播放编码受 Eagle 内置浏览器限制，不引入转码器或额外播放器依赖。
